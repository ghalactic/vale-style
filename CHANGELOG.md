### Added

- Initial implementation of the Ghalactic Vale style
- 29 rules enforcing the Google developer documentation style guide
- Rules cover: word choice, voice and tone, grammar, punctuation, headings,
  accessibility and inclusion, numbers and dates, and readability
- All rules are set to `error` level
- Test fixtures with positive and negative test cases
- CI workflow for automated testing
- Inline suppression support via Vale comments
